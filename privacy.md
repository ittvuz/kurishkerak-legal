# Privacy Policy: kurishkerak-shorts

Last updated: 2026-10-14

**kurishkerak-shorts** is a private tool used by a single person, the owner of the YouTube channel "Ko'rish kerak" (@korishkerak), to upload that channel's own videos (YouTube Shorts) to that same channel using the YouTube Data API.

## What data the app accesses

The app accesses only the Google account of the channel owner who authorizes it. The only permission requested is `youtube.upload`, used to upload videos to the owner's own channel.

## What data the app collects or stores

The app does not collect, store, or process personal data of any other users or viewers. The OAuth refresh token is stored privately on the owner's own server and is used only to upload the owner's videos.

## Sharing

No data is sold, shared with, or disclosed to third parties. Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

The owner can revoke the app's access at any time at https://myaccount.google.com/permissions.
